1Hvað er forrit?

Forrit er listi af skipunum sem tölva fylgir, ein í einu, í réttri röð. Það er eins og uppskrift, nema tölvan skilur ekkert nema nákvæmlega það sem stendur. Ef þú skrifar „kveiktu á pinna 13“ gerir hún það, en hún giskar aldrei á hvað þú áttir við.

Arduino er lítil tölva, kölluð örtölva. Þú skrifar forritið á tölvunni þinni, eða í UNO-herminum. Forritið er síðan þýtt yfir á mál sem örgjörvinn skilur og sent á borðið. Eftir það keyrir borðið forritið sjálft, aftur og aftur, svo lengi sem það fær straum.

Arduino-forrit eru skrifuð í forritunarmálinu C++. Við notum aðeins lítinn hluta af því.

2Beinagrindin: setup og loop

Öll Arduino-forrit hafa sömu beinagrind, tvo hluta sem kallast föll:

void setup() {
  // Hér er það sem á að gerast EINU SINNI í byrjun,
  // t.d. að ákveða hvaða pinnar eru útgangar.
}

void loop() {
  // Hér er það sem á að gerast AFTUR OG AFTUR,
  // t.d. að kveikja og slökkva á ljósi.
}

Orðið void þýðir að fallið skilar engu svari. Þú þarft ekki að skilja það nánar, bara skrifa það. Allt sem tilheyrir setup() er á milli slaufusviganna { og } sem fylgja því, og eins með loop().

3Málfræði forritsins

Forritunarmál hafa stranga málfræði. Ein röng komma og forritið keyrir ekki. Þessar fjórar reglur duga langt:

  1. Hver skipun endar á semíkommu ;. Hún er eins og punktur á eftir setningu.
  2. Slaufusvigar { } afmarka blokk. Hver { verður að hafa sinn }. Inndráttur, þ.e. bil fremst í línu, sýnir hvað er inni í hverju, en tölvan sjálf hunsar hann.
  3. Há- og lágstafir skipta máli. digitalWrite er rétt en digitalwrite og DigitalWrite eru villur.
  4. Athugasemdir byrja á //. Allt aftan við // í línunni er fyrir fólk og tölvan hunsar það. Notaðu athugasemdir til að útskýra hvað forritið gerir.
digitalWrite(13, HIGH);   // kveikir á pinna 13
delay(500);               // bíður í 500 ms = 0,5 s

5Breytur

Breyta er nafn á gildi sem forritið man. Í stað þess að skrifa 13 alls staðar gefum við tölunni nafn:

const int LED = 13;     // LED er tengd við pinna 13
int bid = 500;         // biðtími í ms
  • int segir að breytan sé heiltala. Fyrir tugabrot notum við float, t.d. float spenna = 2.5;. Ath: í forritinu er punktur, ekki komma, í tugabrotum.
  • const þýðir að gildið breytist aldrei. Það hentar fyrir pinnanúmer.
  • Nafnið má ekki byrja á tölu eða innihalda bil eða íslenska stafi. Skrifaðu stada en ekki staða.

Breytur gera forritið auðlesnara. Þegar þú færir LED yfir á annan pinna breytir þú aðeins einni línu.

7Ákvarðanir með if

  
Oft á forritið að gera mismunandi hluti eftir aðstæðum. Þá notum við if og else:


int stada = digitalRead(2);    // les takkann

if (stada == LOW) {            // EF ýtt er á takkann ...
  digitalWrite(13, HIGH);       // ... kveikja
} else {                        // ANNARS ...
  digitalWrite(13, LOW);        // ... slökkva
}

  

    = og == eru ekki það sama
    stada = LOW setur gildið LOW í breytuna. stada == LOW ber saman og spyr hvort stada sé LOW. Í if á nánast alltaf að vera ==.
  

  
Samanburðarvirkjar: == jafnt, != ekki jafnt, < minna en, > stærra en, <= og >=.


  
8Raðskjárinn

  
Arduino hefur engan skjá. Til að sjá hvað er að gerast inni í forritinu sendir það texta og tölur til tölvunnar, á raðskjáinn. Í UNO-herminum er raðskjárinn neðst til hægri og þar er líka Línurit sem teiknar tölurnar.


void setup() {
  Serial.begin(9600);           // opna samband, 9600 bitar á sekúndu
}

void loop() {
  Serial.print("Takkinn: ");    // texti er alltaf innan gæsalappa
  Serial.println(digitalRead(2));
  delay(200);
}

  
Raðskjárinn er besta verkfærið til að finna villur. Ef forritið gerir ekki það sem þú býst við, láttu það prenta gildin og sjáðu hvað er í raun að gerast.
