Stakrænir inngangar

Lesefni fyrir kennslustund 3 · um 25 mínútna lestur · sjálfspróf í lokin

Þegar þú hefur lesið kaflann getur þú:

  • útskýrt hvernig stakrænn inngangur breytir spennu í 1 eða 0
  • útskýrt hvers vegna inngangur má ekki vera fljótandi
  • tengt takka með uppdráttar- eða niðurdráttarviðnámi og reiknað strauminn

1Inngangur les spennu

Sami pinninn getur verið útgangur eða inngangur. pinMode(2, OUTPUT) lætur pinnann gefa spennu, en pinMode(2, INPUT) lætur hann lesa spennu. Með digitalRead(2) fær forritið svarið: 1 (HIGH) eða 0 (LOW).

Inngangur hefur mjög hátt innra viðnám, svo hann dregur nánast engan straum. Hann „hlustar“ bara á spennuna, eins og spennumælir.

2Þröskuldurinn

Inngangurinn þarf að ákveða hvort spennan telst HIGH eða LOW. Á UNO R3 les hann örugglega 1 ef spennan er yfir um 3 V og örugglega 0 ef hún er undir um 1,5 V. Á milli er óvissubil þar sem ekki er hægt að treysta á niðurstöðuna.

3Fljótandi inngangur

Ef ekkert er tengt við inngang er spennan á honum óskilgreind. Hann er sagður fljótandi. Vegna þess hve lítinn straum inngangurinn dregur nægja örsmáar truflanir, t.d. frá höndinni á þér eða nálægum vírum, til að breyta spennunni. Hann les því 1 og 0 á víxl, af handahófi.

Svarið við spurningunni í upphafi: hvorki 0 né 1 með vissu. Þess vegna verður inngangur alltaf að vera tengdur við ákveðna spennu.

4Uppdráttar- og niðurdráttarviðnám

Lausnin er viðnám sem „dregur“ innganginn að ákveðinni spennu þegar ekkert annað er tengt. Takkinn er tengdur þannig að hann getur yfirgnæft viðnámið.

Arduino hefur innbyggt uppdráttarviðnám, 20–50 kΩ á UNO R3. Með pinMode(2, INPUT_PULLUP) er kveikt á því og þá þarf ekkert auka viðnám. UNO-hermirinn notar 35 kΩ.

Öfug rökfræði Með INPUT_PULLUP les pinninn 0 þegar ýtt er á takkann og 1 annars. Þetta ruglar marga í fyrstu.

Viðnámið þarf að vera nógu stórt til að lítill straumur fari þegar ýtt er, en nógu lítið til að halda spennunni þegar takkinn er uppi. Ef ekkert viðnám væri og takkinn tengdi 5 V beint í GND yrði skammhlaup.

5Takkinn á brauðbrettinu

Takkinn í pakkanum hefur fjóra fætur. Fæturnir eru tengdir saman tveir og tveir inni í takkanum. Þegar ýtt er tengjast pörin saman.

6Forrit sem les takka

Þetta forrit kveikir á LED á meðan ýtt er á takkann. Það notar if og raðskjáinn úr kafla 2.

const int TAKKI = 2;
const int LED = 13;

void setup() {
  pinMode(TAKKI, INPUT_PULLUP);   // innbyggt uppdráttarviðnám
  pinMode(LED, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int stada = digitalRead(TAKKI);
  if (stada == LOW) {            // LOW = ýtt á takkann
    digitalWrite(LED, HIGH);
  } else {
    digitalWrite(LED, LOW);
  }
  Serial.println(stada);          // sýnir 1 eða 0 á raðskjánum
  delay(50);
}

7Verkefni í hermunum

Í brauðbrettisherminum

  1. Opnaðu brauðbrettisherminn og veldu dæmið þar sem stilliviðnám er notað sem spennudeilir. Mældu spennuna á miðfætinum á meðan þú færir sleðann. Við hvaða stöðu sleðans færi stakrænn inngangur á UNO R3 frá 0 yfir í 1?

Í UNO-herminum

  1. Fljótandi inngangur. Keyrðu forrit sem prentar digitalRead(2) með pinMode(2, INPUT) og ekkert tengt við D2. Skoðaðu raðskjáinn og línuritið. Breyttu svo í INPUT_PULLUP.
  2. Takki með uppdráttarviðnámi. Opnaðu dæmi 3 · Takki stýrir LED. Mældu spennuna á D2 með takkann uppi og niðri. Reiknaðu strauminn í gegnum takkann þegar ýtt er.
  3. Þröskuldurinn. Tengdu stilliviðnám milli 5V og GND og miðfótinn við D2. Prentaðu digitalRead(2) og færðu sleðann. Við hvaða spennu skiptir lesturinn um gildi?
  4. Gangbrautarljós. Bættu takka við umferðarljósið úr kafla 3. Þegar ýtt er á takkann skiptir ljósið í gult og svo rautt.
  5. Niðurdráttarviðnám. Tengdu 10 kΩ frá D2 í GND og takkann frá D2 í 5V. Notaðu INPUT. Hvað les pinninn núna þegar ýtt er? Berðu strauminn saman við verkefni 2.
  6. Áskorun. Skrifaðu forrit þar sem hver ýting kveikir eða slekkur á LED, á víxl. Vísbending: forritið þarf að muna hvað takkinn las síðast.
